# Cam Ring Thickness Analysis

## Objective
To measure the radial thickness variation of a cam ring using image processing.

## Tools Used
- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib

## Method
1. Load and preprocess image
2. Detect edges using Canny
3. Identify center of ring
4. Measure inner and outer radii
5. Compute thickness at various angles
6. Plot thickness vs angle

## Output
- Detected circles image
- Edge detection image
- Thickness vs angle graph
- CSV data of measurements

## Result
The cam ring thickness was found to be uniform (10 pixels).
